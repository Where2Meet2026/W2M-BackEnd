# 시연용 데이터 (가짜 리뷰)

시연 영상에서 후보 카드에 Gemini 설명이 보이도록 미리 넣어 두는 **가짜 데이터**다.
실제 리뷰로 소개하지 말고, 촬영 후 `demo_cleanup.sql`로 지운다. main/dev에 합치지 않는다.

## 후보 카페 5곳 (커피를 마시러 가는 카페만)
| 카페 | 카카오 장소 ID | 카카오 분류 |
|---|---|---|
| 키하라 | 1963225278 | 음식점 > 카페 |
| 스트라다로스터스 공덕점 | 1447732810 | 음식점 > 카페 |
| 영앤도터스 | 1419437580 | 음식점 > 카페 |
| 스타벅스 공덕점 | 1201355052 | 음식점 > 카페 > 커피전문점 |
| 포멜로빈 공덕점 | 1246535644 | 음식점 > 카페 > 커피전문점 |

## 사용 순서
1. 서버에 `demo/fixed-candidates` 브랜치를 배포하고 환경변수를 넣는다.
   `CANDIDATE_ALLOWED_PLACE_IDS=1963225278,1447732810,1419437580,1201355052,1246535644`
2. DB에서 `demo_seed.sql`을 실행한다. (다시 실행해도 중복되지 않는다)
3. 홍대입구역·용산역·서울역을 각 계정에서 입력하면 위 5곳만 후보로 나온다. 초기 후보 3곳 + 싫어요 과반 교체는 **최대 2번**이다.
4. 촬영 후 `demo_cleanup.sql`을 실행하고 환경변수를 지운다.
